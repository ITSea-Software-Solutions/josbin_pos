# Trainer cheat sheets

Printbare één-pagina referenties voor live Josbin POS-trainingen. Deel ze uit op de trainingsdag. Plak ze boven de kassa. Stop ze in de personeelsmap. Elk vel is één A4, geschikt voor dubbelzijdig printen, ontworpen om tijdens je dienst snel doorgekeken te worden — niet om van kaft tot kaft te lezen.

## Hoe afdrukken

1. Open het `.md`-bestand in een markdown-viewer (VS Code preview, Typora, GitHub web view).
2. **Bestand → Afdrukken** (of `Cmd/Ctrl + P`).
3. In het afdrukvenster: papier **A4**, marges **Standaard**, schaal **100%**, achtergrondafbeeldingen **uit**.
4. Druk dubbelzijdig af als je printer dat ondersteunt — twee cheat sheets per pagina (voor/achter).

> Tip: als een vel buiten de pagina valt in je browser, zet de lay-out op **Staand** en vink "Kop- en voettekst" uit.

## Stijlregels (voor wie deze bijwerkt)

- Eén vel = één A4. Past het niet, schrap iets.
- Knopnamen en schermnamen moeten overeenkomen met de echte app-i18n (Nederlands + Engels).
- Tweetalige labels in het formaat `Nederlands / English` zodat trainees beide tegelijk zien.
- Geen verzonnen sneltoetsen of functies. Als je het opschrijft, gaat de trainee het proberen.
- Gebruik iconen (emoji) en tabellen zodat het scanbaar blijft. Trainers lezen deze hardop voor.
