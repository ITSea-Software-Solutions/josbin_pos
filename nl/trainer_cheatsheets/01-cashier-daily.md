# Kassier — Dagelijkse werkstroom
**Josbin POS · Kassamedewerker dagelijks**

---

## ☀️ 's Ochtends — Begin je dienst

1. **Log in** met e-mail + wachtwoord op de POS-terminal.
2. **Kies je vestiging** (overgeslagen als er maar één is).
3. **Kassa openen**-scherm:
   - Tik op je kassa (bv. *Kassa 1*). Grijs = iemand anders heeft hem open.
   - Vul het **Openingsbedrag** in op het numpad (bv. `200.00`).
   - Tik op **Kassa openen**.
4. Je komt op het POS-verkoopscherm. Je naam + kassa staan in de bovenbalk. ✅

---

## 🛒 Tijdens je dienst — Verkopen

```
  ┌─────────────────────────────┬─────────────────┐
  │  PRODUCTENRASTER (tik/scan) │  WINKELWAGEN → Betalen │
  └─────────────────────────────┴─────────────────┘
```

| Stap | Actie |
|------|-------|
| 1. Product toevoegen | Tik op een tegel, OF scan de barcode (geen toets nodig), OF type barcode + **Enter** |
| 2. Regel aanpassen | Tik op een winkelwagenregel → bewerk aantal / prijs / korting / BTW |
| 3. Klant (optioneel) | Winkelwagen → **Klant** → zoek of **+ Nieuw** |
| 4. Korting (optioneel) | Per regel: tik op de regel. Hele bon: onderaan winkelwagen |
| 5. Bon vasthouden | **Bon vasthouden** — laad later direct terug |
| 6. **Afrekenen** | **Contant**, **Pin**, of **Gemengd**. Contant: type ontvangen bedrag → wisselgeld verschijnt live |
| 7. Bon | **Printen**, **E-mail** en/of **WhatsApp** (typ het nummer, `+597` komt er vanzelf bij; WhatsApp opent klaar om te verzenden) — lade springt automatisch open bij contant |
| 8. Nieuwe verkoop | **Nieuwe verkoop** → winkelwagen wordt leeg |

🔍 **Barcodescanner:** USB-scanners typen in het actieve veld. Houd de focus op het POS-scherm — geen speciale toets.
⌨️ **Touchscreen?** Schakel het toetsenbord op het scherm in vanuit de bovenbalk.

### ⚡ Sneltoetsen (sneller dan de muis)

| Toets | Actie |
|-------|-------|
| **F2** | Huidige bon vasthouden (parkeert de winkelwagen) |
| **F9** | Opent het betaalscherm — alleen als er items in de winkelwagen zitten |
| **F4** | Start een nieuwe verkoop nadat er net een is afgerond |
| **F12** | Schakel het toetsenbord op het scherm aan/uit |
| **Esc** | Sluit het betaal-, bon- of toetsenbordvenster |

Sneltoetsen worden overgeslagen terwijl je typt in een zoekvak of numpad, dus ze verstoren je invoer nooit.

---

## 🌙 Einde dienst — Kassa sluiten

1. Bovenbalk → rode **Kassa sluiten**.
2. **Sessieoverzicht** — controleer openingsbedrag, contant + pin verkopen, totaal. Tik op **Ga verder met kassasluiting**.
3. **Tel het geld:**
   - Tel elk biljet + munt fysiek. Type het totaal op het numpad.
   - Als ≠ "Verwacht in la", verschijnt rode **Tekort** of groene **Overschot**.
   - **Opmerking is verplicht bij elk verschil** — bv. *"telfout"*. De Volgende-knop blijft uitgeschakeld zonder opmerking.
4. **Bevestig** → **Kassa definitief sluiten**.
5. **Klaar ✅** Tik op **Uitloggen**, of **Heropening aanvragen** als je dat nodig hebt (manager moet goedkeuren).

---

## 🆘 Problemen oplossen

| Probleem | Wat doen |
|----------|----------|
| Product scant niet | Zoek op naam, of tik op de tegel. Vraag de manager om de barcode opnieuw in te voeren. |
| Printer drukt niet af | E-mail de bon in plaats daarvan. Controleer papier + kabel. Bel de manager — annuleer niet. |
| Klant wil terugbetaling | **Bel de manager.** Kassiers kunnen niet terugbetalen of annuleren. |
| Kassa gaat niet open ("In gebruik") | Iemand heeft hem open. Vraag of die persoon sluit, of de manager sluit hem in Dashboard → Kassabeheer. |
| Verschil >SRD 50 bij sluiten | **Niet sluiten.** Tel opnieuw. Nog steeds verschil? Bel de manager. |
| Per ongeluk gesloten | Tik op **Heropening aanvragen** op het gesloten scherm. Manager keurt goed in Dashboard → Kassabeheer. |
| App vastgelopen | Wacht 10s. Sluit + heropen. Verkopen zijn lokaal opgeslagen — niks kwijt. |

---

## 🚫 Wat je NIET kunt

- Geen terugbetalingen of annuleringen — **alleen manager**.
- Geen prijswijzigingen buiten de huidige winkelwagenregel.
- Geen totalen van andere kassiers zien — totalen in de bovenbalk zijn alleen jouw sessie.
- Geen kassa heropenen na sluiten zonder goedkeuring van de manager.
- Geen kortingsregels of BTW-tarieven wijzigen — die stelt het hoofdkantoor in.

---

> **Gouden regel:** elke verkoop hoort bij JOUW open sessie. Open aan het begin, sluit aan het einde. Tel zorgvuldig. Noteer altijd verschillen — kleine zijn normaal en worden nooit bestraft.
