## Quick reference — daily workflow

```
START OF DAY
  1. Open Josbin POS application
  2. Log in with your username and password
  3. Select your store
  4. Manager: set today's exchange rate (Exchange Rate screen)

DURING THE DAY
  5. Scan or tap products to add to cart
  6. Add customer if needed
  7. Apply discounts if needed
  8. Accept payment (cash / card / mixed)
  9. Print or email receipt
  10. Cash drawer opens automatically

END OF DAY
  11. Manager: go to End of Day screen
  12. Count the cash in the drawer
  13. Enter the counted amount
  14. Close the Z-Report
  15. System syncs sales to headquarters
```

## Important terms

| Term | Meaning |
|------|---------|
| **BTW** | Sales tax (Belasting over de Toegevoegde Waarde) — currently 10% in Suriname |
| **SRD** | Surinamese Dollar — all prices in this system are in SRD |
| **Z-Report** | End-of-day register close. Finalises the day and sends data to headquarters |
| **X-Report** | Mid-day snapshot of sales. Does NOT close the register |
| **Hold Bill** | Save a cart temporarily to serve another customer, then come back to it |
| **ESC/POS** | The command language used by thermal receipt printers |
| **Sync** | Sending today's sales data to the central server / head office |
