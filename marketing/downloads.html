Upgrading? Never uninstall first. Close the app (⏻ Exit on the login screen), then run the newer installer / install the newer APK over the old one — your server address, settings and login are kept.
Bijwerken? Nooit eerst de-installeren. Sluit de app (⏻ Afsluiten), installeer de nieuwe versie over de oude heen.

After installing

  1. Open Josbin POS and tap ⚙ Server on the login screen.
  2. Enter your store's server address (e.g. 192.168.0.250:8080) → Test → Save.
  3. Log in with the account your manager created. Hardware setup lives under Settings → Hardware.
