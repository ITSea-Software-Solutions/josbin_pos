# Trainer Cheat-Sheets

One-page printable references for live Josbin POS training sessions. Hand them out on training day. Tape them above the till. Slip them into the staff binder. Each sheet is a single A4, double-sided friendly, designed to be skimmed mid-shift — not read cover to cover.

## How to print

1. Open the `.md` file in any markdown viewer (VS Code preview, Typora, GitHub web view).
2. **File → Print** (or `Cmd/Ctrl + P`).
3. In the print dialog: paper **A4**, margins **Default**, scale **100%**, background graphics **off**.
4. Print double-sided if your printer supports it — two cheat sheets per page (front/back).

> Tip: if a sheet spills over the page in your browser, switch the layout to **Portrait** and untick "Headers and footers".

## Style rules (for anyone updating these)

- One sheet = one A4. If it spills to a second page, cut something.
- Button names and screen names must match the actual app i18n (Dutch + English).
- Bilingual labels in the format `English / Nederlands` so trainees see both at once.
- No invented shortcuts or features. If you write it, the trainee will try it.
- Use icons (emoji) and tables for scan-ability. Trainers read these out loud.
