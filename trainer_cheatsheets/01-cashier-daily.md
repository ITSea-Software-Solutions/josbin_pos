# Cashier — Daily Workflow
**Josbin POS · Kassa-medewerker dagelijks**

---

## ☀️ Morning — Start your shift / Begin van je dienst

1. **Log in** with email + password on the POS terminal.
2. **Pick your store** (skipped if only one).
3. **Open Register / Kassa openen** screen:
   - Tap your register (e.g. *Kassa 1*). Greyed-out = someone else has it open.
   - Enter the **Opening float / Openingsbedrag** on the numpad (e.g. `200.00`).
   - Tap **Open register / Kassa openen**.
4. You land on the POS sell screen. Your name + register show in the top bar. ✅

---

## 🛒 During the shift — Selling / Tijdens je dienst

```
  ┌─────────────────────────────┬─────────────────┐
  │  PRODUCT GRID (tap or scan) │  CART → Pay     │
  └─────────────────────────────┴─────────────────┘
```

| Step | Action |
|------|--------|
| 1. Add product | Tap a tile, OR scan barcode (no key needed), OR type barcode + **Enter** |
| 2. Adjust line | Tap a cart line → edit qty / price / discount / BTW |
| 3. Customer (optional) | Cart → **Customer / Klant** → search or **+ New** |
| 4. Discount (optional) | Per line: tap the line. Whole bill: bottom of cart |
| 5. Hold the bill | **Hold bill / Bewaar bon** — load instantly later |
| 6. **Pay / Betalen** | **Cash / Contant**, **Card/PIN**, or **Mixed**. Cash: type tendered → change shows live |
| 7. Receipt | **Print** and/or **Email** — drawer pops automatically on cash |
| 8. New sale | **New sale / Nieuwe verkoop** → cart clears |

🔍 **Barcode scanner:** USB scanners type into focused field. Keep focus on POS screen — no special key.
⌨️ **Touchscreen?** Toggle on-screen keyboard from the top bar.

### ⚡ Keyboard shortcuts (faster than the mouse)

| Key | Action |
|-----|--------|
| **F2** | Hold the active bill (parks the cart) |
| **F9** | Open the payment screen — only when cart has items |
| **F4** | Start a new sale after one just completed |
| **F12** | Toggle the on-screen keyboard |
| **Esc** | Close the payment / receipt / keyboard popup |

Shortcuts are skipped while typing in a search box or numpad, so they never fight your input.

---

## 🌙 End of shift — Close register / Einde dienst

1. Top bar → red **Close register / Kassa sluiten**.
2. **Session summary** — review opening float, cash + card sales, total. Tap **Proceed to close register / Ga verder met kassasluiting**.
3. **Count the cash / Tel het geld:**
   - Count every note + coin physically. Type total on the numpad.
   - If ≠ "Expected in drawer / Verwacht in la", red **Shortage / Tekort** or green **Surplus / Overschot** appears.
   - **Note is required if any difference** — e.g. *"telfout"*. Next button stays disabled without it.
4. **Confirm** → **Close register now / Kassa definitief sluiten**.
5. **Done ✅** Tap **Log out / Uitloggen**, or **Request re-open / Heropening aanvragen** if you need (manager must approve).

## 🆘 Troubleshooting / Problemen oplossen

| Problem | What to do |
|---------|------------|
| Product won't scan | Search by name, or tap the tile. Tell manager to re-enter barcode. |
| Printer not printing | Email the receipt instead. Check paper + cable. Call manager — don't void. |
| Customer wants a refund | **Call the manager.** Cashiers cannot refund or void. |
| Register won't open ("In use") | Someone has it open. Ask them to close, or manager closes it in Dashboard → Registers. |
| Discrepancy >SRD 50 at close | **Don't close.** Recount. Still off? Call manager. |
| Closed by accident | Tap **Request re-open** on closed screen. Manager approves in Dashboard → Registers. |
| App froze | Wait 10s. Close + reopen. Sales saved locally — nothing lost. |

---

## 🚫 What you CAN'T do

- No refunds or voids — **manager only**.
- No price changes beyond the current cart line.
- No seeing other cashiers' totals — top-bar totals are your session only.
- No reopening your closed register without manager approval.
- No changing discount rules or BTW rates — HQ sets those.

---

> **Golden rule:** every sale belongs to YOUR open session. Open at start, close at end. Count carefully. Always note discrepancies — small ones are normal and never punished.
